# Privacy policy

Effective: September 15, 2026

Web App Tabs for Firefox does not collect, store, sell, or transmit personal
data, browsing activity, technical data, telemetry, or analytics.

When the user explicitly opens another tab, the extension reads the active
tab's URL locally and asks Firefox to open that URL in the same window. For
ChatGPT pages, it locally substitutes `https://chatgpt.com/` so the new tab
starts a fresh chat. The extension does not send this information anywhere;
the newly opened page is loaded normally by Firefox and is governed by that
website's own privacy policy.

Changing the keyboard shortcut uses Firefox's local extension commands API.
No extension settings are synchronized or transmitted by this extension.

Questions can be sent through the support contact on the extension's Mozilla
Add-ons listing.
