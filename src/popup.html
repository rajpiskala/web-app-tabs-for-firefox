Web App Tabs

Multiple tabs, one web-app window.

iWhat counts as a web app?

It is a site you added with Add tab to taskbar and opened from its standalone Windows taskbar icon. Here, opening another tab reveals Firefox's hidden tab strip.

In a regular Firefox window, the same action simply opens the current page again in another tab.
