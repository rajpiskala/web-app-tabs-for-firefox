Web App Tabs

Multiple tabs, one web-app window.

Use this inside the site's standalone Windows web-app window.

iWhat counts as a web app?

In Firefox, it is a site you added with Add tab to taskbar and then opened from that site's standalone icon on the Windows taskbar.

This extension is for that app-style window, not a site open in a regular Firefox window. It adds tabs; it does not turn a regular tab into a web app.

Keyboard shortcut

Click, then press a Firefox-compatible key combination.
